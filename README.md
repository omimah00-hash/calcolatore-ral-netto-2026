# Calcolatore RAL → Netto 2026

Calcolatore dello stipendio netto partendo dalla RAL (Retribuzione Annua Lorda) per dipendenti del settore privato in Italia.

## Caratteristiche

- **IRPEF 2026** con scaglioni reali (23%–33%–43%)
- **Contributi INPS** differenziati per tipo di contratto (9,19% indeterminato/determinato, 5,84% apprendista)
- **Addizionali regionali** con scaglioni per tutte le 20 regioni + province autonome
- **Addizionali comunali** con aliquote e soglie di esenzione per tutti i capoluoghi italiani
- **Detrazioni fiscali**: lavoro dipendente, coniuge, figli, altri familiari
- **Agevolazioni**: trattamento integrativo (ex bonus Renzi), fondo pensione deducibile, premi di produttività°° con opzione imposta sostitutiva

## Come usarlo

1. Scarica il file `calcolatore-ral-netto-2026-v3.html`
2. Aprilo in un browser (Chrome, Firefox, Edge, Safari)
3. Inserisci la RAL, scegli regione e comune, compila le agevolazioni
4. Clicca su "Calcola" per vedere il dettaglio completo

## Note

- I dati delle addizionali sono basati sulle delibere ufficiali MEF 2026
- Il calcolo è una stima semplificata: busta paga reale può variare per CCNL, giorni di detrazione, welfare, ecc.
- Non sostituisce consulenza professionale
